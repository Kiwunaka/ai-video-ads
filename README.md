# AI Video Ads

Скилл для Codex: видеореклама, мемы по референсам, замена персонажей, озвучка, lip-sync, монтаж и проверка готового видео.

**[Скачать ZIP](https://github.com/Kiwunaka/ai-video-ads/releases/latest/download/ai-video-ads.zip)** · [Читать SKILL.md](ai-video-ads/SKILL.md)

## Установка

1. Скачайте ZIP и распакуйте папку `ai-video-ads` в `~/.codex/skills/`.
2. Вызовите скилл в Codex: `$ai-video-ads`.
3. Укажите свой бренд, продукт, референсы, доступных провайдеров и бюджет. Добавьте собственные логотип и материалы продукта.

На Windows папка обычно находится в `%USERPROFILE%\.codex\skills\`.

Пример запроса:

> Используй $ai-video-ads. Сделай три варианта рекламы моего бренда: адаптацию тренда с оригинальным звуком, нативный мем и продуктовый ролик. Референсы и логотип приложены. Провайдеры и лимит расходов — в моём задании.

## В комплекте

- Три формата работы: адаптация тренда, самостоятельный мем, продуктовая реклама.
- Подготовка персонажей, перенос сцены и шаблоны промптов.
- Работа с оригинальным звуком, TTS, аудиореференсами и lip-sync.
- Монтаж, рекламная концовка и техническая проверка результата.
- `scripts/mix_audio.py`: универсальный сборщик WAV из дорожек аудио и MP4, с точными in-points и позициями.

Скилл универсальный: логотипов заказчика, частной истории переписки, ключей API и настроенных аккаунтов внутри нет. Он не включает сгенерированные рекламные видео. Бренды и сервисы в примерах служат референсами постановки.

Для аудиосборщика нужны Python и FFmpeg/ffprobe; сторонние Python-пакеты не требуются. Генерация медиа требует доступного провайдера и согласованного бюджета. Названия моделей в справочниках — примеры: доступность, цену и схему нужно проверять перед запуском.
