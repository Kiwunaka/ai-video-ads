# Монтаж, микс и проверка

## Не теряй звук источника

В исходной партии почти у всех H3-видео был аудиопоток, однако сборщик использовал видео с `muted` / `data-volume=0` и собирал только отдельные музыку и диктора. Некоторые промпты одновременно запрещали речь. Это две разные причины немой сцены: звук не создан либо создан и потерян в монтаже.

Немая картинка с музыкальной подложкой не решает запрос на оригинальное звучание. До монтажа проверь реальные потоки каждого используемого файла:

```powershell
ffprobe -v error -show_entries stream=codec_type,codec_name,sample_rate,channels,duration -of json source.mp4
```

Для простого извлечения оригинала:

```powershell
ffmpeg -v error -y -i source.mp4 -map 0:a:0 -vn -ar 48000 -ac 2 -c:a pcm_s24le original.wav
```

Команда требует аудиопоток: не заменяй ошибку отсутствия звука молчанием. У одних шаблонов аудио действительно нет; тогда нужен другой оригинал, а не усиление пустого файла.

## Один готовый микс

[mix_audio.py](../scripts/mix_audio.py) собирает WAV 48 kHz / stereo / 24-bit из аудио и видеоклипов. Нужны Python и FFmpeg/ffprobe; сторонних Python-библиотек нет. Скрипт не выбирает сцену, не генерирует речь и не распознаёт музыку.

Manifest содержит общую `duration` и `clips`. Пути `src` относительны manifest или абсолютны. `start` — место в итоговом миксе, `source_start` — in-point в источнике, `duration` — длина куска; `gain` — линейная громкость. `fade_in` и `fade_out` задаются в секундах и по умолчанию равны нулю.

Пример: десять секунд оригинального ролика, затем рекламная реплика. **Длительности примера нужно заменить фактическими**, а не обрезать речь ради них.

```json
{
  "duration": 12.7,
  "clips": [
    {
      "src": "refs/original.mp4",
      "start": 0,
      "source_start": 0,
      "duration": 10,
      "gain": 1,
      "fade_out": 0.04
    },
    {
      "src": "assets/brand-voice.wav",
      "start": 10.35,
      "source_start": 0,
      "duration": 2.08,
      "gain": 1
    }
  ]
}
```

```powershell
python <skill-dir>/scripts/mix_audio.py mix.json --output final-mix.wav
```

При неправильной длине, отсутствии аудиопотока или выходе клипа за пределы монтажа скрипт останавливается. Он не зацикливает и не растягивает источник. Микс сохраняет заданные уровни; финальный лимитер предотвращает перегруз по отсчётам, но не выравнивает perceived loudness и не доказывает комфортную слышимость. Для голоса на фоне музыки подбери уровни или осмысленное ducking отдельно.

В композиции оставь один активный `final-mix.wav`, отключив дубликаты звука видео и отдельной речи. Если рендеришь через FFmpeg, явно замени аудиопоток готовым миксом. Одинаковое окончание звука и изображения проверь до mux; `-shortest` может скрыть ошибку обрезанием.

## Склейки и бренд

Для каждого куска нужны точные source in/out и позиция в монтаже. Не переноси таймкоды со старого файла на новую генерацию с иной длиной. Если модель поменяла скорость реплики, пересмотри синхронизацию.

Режь по завершению действия и по движению камеры. Если референс содержит важную паузу или звуковой вход, сохрани его. Не добавляй freeze/loop для заполнения отсутствующего материала. Сложную физику лучше заменить двумя понятными планами, чем сдавать мутирующий объект.

Настоящий UI в мемном ролике можно вынести в короткий конец. Для продуктового формата покажи достаточно интерфейса, чтобы зритель понял действие. В одной прошлой партии демонстрация занимала восемь секунд; это не обязательная длительность всех будущих мемов.

Концовка без грязного стола: чистый фон, настоящий знак и название, короткая мысль, нужные иконки сервисов и реальный скрин. Анимация служит появлению и чтению. Поставь реплику в пределах конца; не обрывай последнее слово. Не добавляй чужие иконки как утверждение о партнёрстве.

Сохраняй исходный кадр, если вертикальный кроп уничтожит смысл. «Сумерки» в этой сессии сохраняли горизонтальный формат. Размер экспорта не превращает мягкий 720p-источник в нативно сгенерированный 1080p.

## Studio и экспорт

Если глитчит Studio, сравни с MP4. Ищи дубли дорожек, неправильные media offsets и повторный запуск при seek. Один подготовленный микс уменьшил проблему многодорожечного воспроизведения в этой сессии. Исправление preview не заменяет проверки экспортированного файла, и наоборот.

Сохраняй предыдущую пригодную версию до перезаписи. Hardlink не является независимой копией: прямое открытие того же inode на запись изменит обе ссылки. Для новых рендеров используй временный файл и атомарную замену после успеха; для изменяемых manifest/HTML нужна независимая копия или такой же способ записи.

## Проверка готового результата

Техническая проверка полного файла:

```powershell
ffmpeg -v error -i final.mp4 -f null NUL
ffprobe -v error -show_entries format=duration:stream=codec_type,codec_name,width,height,r_frame_rate,sample_rate,channels -of json final.mp4
ffmpeg -hide_banner -i final.mp4 -vn -af volumedetect -f null NUL
```

Проверь отдельно:

- **Сцена:** старт, изменение ситуации и развязка видны; нет случайного возврата оригинальных актёров и новых лишних конечностей.
- **Речь:** говорит назначенный участник, рот открывается по слогам; совпадение проверено в начале, середине и конце. Другая поза/голос не скрывает плохой lip-sync.
- **Звук:** оригинальная музыка вместе со всеми нужными слоями сохранена; мемная реплика слышна и попадает в событие; нет двойного голоса, кликов и обрезанных слов.
- **Финал:** логотип правильный, UI настоящий, адрес/CTA прочитывается, последние кадры не возвращают старую заставку.
- **Выдача:** обычный плеер запускает нужный MP4; галерея и ZIP действительно содержат последнюю редакцию всех заявленных номеров.

Для контактных листов и необязательного fingerprint используй доступный инструмент анализа медиа. Спектрограмма, корреляция и ffprobe не являются прослушиванием или творческой оценкой. Если слуховая проверка недоступна, скажи об этом прямо и дай удобный плеер, не выдавая проверку метаданных за проверку звучания.
